# Mission: ArkadeOS Smart Contracts

## Why

Build a reliable blockchain mental model, understand how ArkadeOS changes the smart-contract pattern on Bitcoin, and use that understanding to evaluate game mechanics and integration designs.

## Success looks like

- Explain the difference between an EVM-style contract and an Arkade contract.
- Sketch a game mechanic as a Bitcoin Script/VTXO spending policy.
- Estimate which parts of a game flow consume sats, operator fees, or on-chain miner fees.

## Constraints

- Start with a general introduction, then specialize in Arkade.
- Prefer practical game and integration examples over protocol archaeology.
- Treat fees as quote- and network-dependent; verify current numbers before implementation.

## Out of scope

- Writing production contract code in the first lesson.
- Full Bitcoin Script or cryptographic implementation details.
- Token economics or a complete game architecture.
