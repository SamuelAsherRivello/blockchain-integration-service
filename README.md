# blockchain-integration-service

Reusable browser-first BTC Lightning integration for games. Currently in planning; implementation has not started.

- [Original project brief](BGS_PROJECT_BRIEF.md)
- [Design discussion](docs/design-discussion.md)
- [OpenSpec configuration](openspec/config.yaml)

The confirmed repository name is `blockchain-integration-service`. The source brief retains its original BGS terminology; product and API naming remain open.

React + TypeScript. Signet only. Arkade SDK only for v1. No custom application server or simulated transaction outcomes. The game remains separate and playable without integration connectivity.
