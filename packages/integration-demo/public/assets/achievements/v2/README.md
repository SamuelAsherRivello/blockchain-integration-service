# Achievement trophies v2

Olympic medal colors: level 1 bronze, level 2 silver, and level 3 gold. Each transparent 64 by 64 PNG carries its matching digit. Admin achievement presets use these URLs. The v1 artwork remains available for existing minted metadata.

Created with the built-in imagegen tool, then resized with nearest-neighbor sampling for the existing icon contract.

Prompts: Recolor each original pixel-art trophy while preserving its shape, framing, transparent background and matching digit. Level 1 uses copper-brown bronze with chocolate shadows and pale copper highlights. Level 2 uses cool neutral silver with gray shadows and white highlights. Level 3 uses bright yellow gold with amber shadows and pale yellow highlights. Make all three finishes visually distinct. Correct the bronze digit to a clear outlined 1 and retain genuine alpha transparency.

Preserve this published version for existing metadata. Future revisions should use a new version directory.
