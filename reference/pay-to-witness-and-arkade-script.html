Pay-to-Witness concepts

An output locks value with a rule. A witness supplies the evidence that satisfies that rule when the value is spent.

Core vocabulary

Output
A Bitcoin coin-like value plus a locking condition.
ScriptPubKey
The locking program attached to an output.
Witness
Spending evidence supplied by the input: signatures, public keys, preimages, or other stack data.
Witness program
A compact commitment in a SegWit output that tells the spender what witness rule to satisfy.
Script path
A branch of conditions selected when spending, especially in Taproot.

Game translation

“Winner claims prize” can mean: winner signature required; a referee signature required; a secret preimage reveals the winning path; or a timeout opens a refund path. The witness is the proof, not the game’s descriptive UI event.
